# F1 Weather

F1 Weather is a simple weather website that shows the current weather information for a selected city. I built this project using HTML, CSS, and JavaScript while working with a weather API.

##Features

* Search weather by city
* Shows current temperature and weather condition
* Displays humidity and wind speed
* Simple and responsive design
* Uses real-time weather data

## Technologies Used

* HTML
* CSS
* JavaScript
* OpenWeatherMap API

This project was created as a practice project to improve my frontend development and JavaScript skills.
